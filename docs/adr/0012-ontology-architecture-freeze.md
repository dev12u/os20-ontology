# ADR 0012 — Broad ontology architecture freeze

## Status

Accepted (Prompt 5)

## Decision

Identity, package/lock/registry reuse, `OntologyRuntime` as in-process semantic authority, and product-thin surfaces are frozen. See [ontology-spec-v1.md](../ontology-spec-v1.md) and [ontology/freeze.md](../ontology/freeze.md).
