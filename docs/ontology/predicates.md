# Predicates

Built-in relations remain **Rust handlers**. Ontology metadata (`PredicateRuntimeSpec`) constrains source/target types and semantic domain. No scripts, no SQL triggers.

`Flow` endpoints must be assignable to `PhysicalThing` and must not be quantity types (`OS20-E4015`).

Queries: `predicates_in_domain`, `validate_relation`, `validate_predicate`.
