# Evolution (runtime)

`Deprecated` / `ReplacedBy` / `SplitInto` / `MergedInto` are **guidance**. Locked v1 retains v1 `TypeId`s; v2 does not silently rewrite them.

`ontology_diff` categories: type add/remove, specialization change, feature add/remove/type change, predicate change, domain membership, deprecation, replacement mapping. Public breaking changes advise **Major** via the existing SemVer shape (`SemVerAdvice`).
