# Artifacts

Frozen: `ContentDigest`, `ArtifactDigest`, `ProvenanceDigest`. Ontology adds **roles**: Model, Geometry, Behavior, Simulation, Test, Documentation, SourceCode, Manufacturing.

`representedBy` / `describes` / `sourceArtifact`. Paths are not identity.

Vendor tools (SolidWorks, Ansys, …) are instances of `CADTool`/`SimulationTool`, not core classes.
